# GINLANG

GINLANG 的中文个人博客，记录随笔、日记和读书时的想法；受邀朋友的作品也可以保留署名与独立页面。使用 Astro 生成静态页面，发布在 GitHub Pages。

视觉规范与动效说明见 [ART_DIRECTION.md](ART_DIRECTION.md)。新增作者、作品和专题的步骤见 [编辑与发布手册](docs/editorial-workflow.md)。

## 写一篇新文章

在 src/content/posts/ 新建 Markdown 文件，例如 2026-10-01-autumn-note.md：

    ---
    title: 秋天经过的时候
    date: 2026-10-01
    category: essay
    themes: [life, direction]
    author: ginlang
    excerpt: 给文章写一句简短的介绍。
    draft: false
    ---

    从这里开始写正文。

category 可用 essay（随笔）、diary（日记）、book（书摘）或 short（短句）。写作中的文章将 draft 设为 true，发布前改成 false。

`themes` 可选，支持 philosophy（想法与选择）、life（日常与时间）、love（人与人之间）、freedom（自由与边界）、direction（路与方向）。只按文章实际内容填写。当已发布文章至少有八篇，且同一主题至少有三篇时，文章页才会从真实作品生成阅读路线；同一篇文章不会在两条路线中重复出现。

`author` 对应 `src/content/authors/` 中的作者 ID。首页会按已发布的真实内容展示作者和作品；未配置正式专题时不会出现空专题入口。

## 本地预览和构建

    npm install
    npm run dev
    npm run build

静态文件会生成到 dist/。推送到 GitHub 仓库的 main 分支后，GitHub Actions 会自动构建并发布。

## 内容与视觉

- 首页以标题、两个清晰的入口按钮和水彩画册开场，作者资料作为独立段落接在刊脚之后，再展示最近文章、客席作者、已发布的专题、页边札记、可切换的风景和分类目录。手机端按标题、按钮、画册、作者资料的顺序阅读；桌面端保留左文右画。专题未配置时自然隐藏；作品节选和作者数量由真实内容生成。每个板块至多一个动作链接，按钮做减法、内容展示做加法。
- 首屏按钮分两级：主入口实心、次入口描边，保证一眼可辨。「随机翻一页」放在「最近写的」标题旁，作为安静的文字按钮。
- 封面画册每 6 秒翻一张，支持前后切换（按钮或键盘左右方向键）、暂停、继续与手机横向滑动；点击画面可以放大翻看，关闭后继续原来的轮播状态。刷新时会更换首图。网页副本位于 `public/hero-watercolors/`，原始 PNG 保留在用户提供的素材文件夹。画册图片在 `src/data/heroWatercolors.ts` 中配置，路径兼容 `/ginlang/`。每张画另有 480w / 800w 两档 WebP 副本，按屏幕尺寸自动选择；更换原图后运行 `node scripts/build-hero-variants.mjs` 重新生成并一并提交。画册下方一条灰绿细线随翻页推进，只暗示位置，不显示数字。选定的首图在页面解析时即开始预载，其余按需加载。浏览器启用减少动态效果时，画册默认暂停。
- 首页画册下方通向 `/album/` 相簿页。相簿按作者分开：GINLANG 的相册排在最前，客席作者的相册作为次级列表；每位作者的相册有稳定地址（`/album/<作者 id>/`），可从作者主页直接进入，相册页也能回到作者主页。相册数据在 `src/content/albums/<作者 id>.json`，没有公开照片时只显示「暂未公开照片」，不借用其他图片填充；作者主页的照片推荐与相册页读取同一份数据。首页水彩轮播的图片与替代文本由 `src/data/heroWatercolors.ts` 维护。
- 画册边有「做张小卡片」入口，可从现有水彩和已标注出处的短句中选取内容，在浏览器内排版并下载 PNG。图片完整放进纸白画框，文字列在下方；不会向网站上传个人数据。选句在 `src/components/CardMaker.astro` 中维护，仍从 `src/data/whispers.ts` 的有效句库读取。
- 留白与暖纸白仍是主体，手绘插画采用低饱和的蓝、绿和陶土色。透明的蓝蝶使用侧展的艺术化蝶翼，不绘制深色虫身。日记页的深色月夜图已换成带一弯月亮的明亮街景。
- 首页「换一扇窗」可以手动切换海边、林间和街角；不自动播放。插画放在 public/，路径由页面组件引用。
- 首页作者资料、作者目录和个人页共用海边插画头像与林间水彩背景；首页背景保持原画横幅比例，头像与图片分开。地点「成都」和原样日期「07/02/18」由 `src/content/authors/ginlang.json` 提供，日期不预设用途。首页的 About、英文问候语与作者简介的中英文引文使用局部手写字体；中文出处留在作者数据中供核对，不在页面显示。网页资源位于 `public/authors/`，原图的本地备份位于未发布的 `source-art/`。
- 首页有「随机翻一页」和随刷新轮换的页边札记。今日笺下方会在读过文章后安静地出现一行「上次读到《……》」，点击即可回去继续；记录只保存在当前浏览器。
- 各栏目都有「页边札记」。`src/data/whispers.ts` 收录有出处的白话短摘录，围绕哲理、人生、爱情、自由和方向；全站共用作者交错的洗牌袋，跨页面与同一标签页刷新不重复，轮完再洗牌。核对资料见 [选句来源](docs/whisper-sources.md)。
- 「抽一张今日笺」放在首页，读者可以在网页上写草稿、复制或清空；不同笺语的草稿分别保存在自己的浏览器，也可在「我的书桌」整理和导出。关于页用作者文章入口替换。首页末尾和关于页五段待填内容仍显示「此处需要您亲自填写」；在 `src/data/author.ts` 替换这些文字即可。
- 页脚使用不蒜子统计累计访问人次；静态部署后加载，外部服务暂不可用时显示破折号。同一浏览会话只计数一次，刷新页面不会累加；最近一次读到的数字会缓存在浏览器里继续显示。本地开发不会请求计数服务。统计服务的访问记录处理方式见[不蒜子说明](https://www.busuanzi.cc/doc.php)。

## 阅读与交互

- 文章支持阅读进度、相邻文章和复制链接。长文章出现自动目录，滚动时目录会标出当前所在的小节；阅读书签能保存当前文章的大致阅读位置，并在再次打开时继续阅读，位置只保存在当前浏览器。夜间主题下，画框类图片带柔和投影。
- 阅读设置默认使用浅色纸页，也可调整为跟随系统或夜间主题，并可修改字号、字体风格和正文宽度；偏好保存在当前浏览器。
- 搜索支持文章标题、摘要、正文、署名和分类，也可按 Ctrl+K 或 ⌘K 打开；正文命中时显示附近的一小段，匹配的关键词会在结果中高亮，用 ↑/↓ 在结果间移动、回车打开。搜索词可通过带 `?q=` 的网址分享。打开搜索时会预先读取索引。
- 「我的书桌」位于 `/desk/`，汇集手动收藏的文章、原有阅读书签和今日笺草稿，可导出为 Markdown。所有数据只保存在当前浏览器，换设备或清除浏览器数据后不会自动同步；导出文件适合自行备份。
- 文章页可用 ←/→ 方向键在相邻文章间切换；支持系统分享的设备可以直接分享当前文章。
- 向下滚动后右下角出现「回到页首」按钮；文章页它会自动避开阅读书签的位置。页脚标注最近一次的更新日期。
- 页头在阅读向下滚动后收成一条紧凑的细栏，便于继续跳转；回到页首附近时恢复完整高度。
- 页面切换始终保留短促的纸页淡入过渡；封面文字、蓝蝶、文章目录、图片与不同栏目使用各自的轻量动效；风景切换交叉淡入。系统选择减少动态效果时，其余连续动画会停止或缩短。
- 页眉和页脚都能打开分享面板，一键复制公开网址；支持系统分享的设备也可直接转发。
- RSS 订阅位于 /rss.xml，正文以全文输出（content:encoded）；站点地图位于 /sitemap.xml。
- 页面包含 canonical、Open Graph、Twitter 卡片和结构化数据（全站 WebSite，文章页 BlogPosting，作者页 ProfilePage）。每篇文章在构建时由 SVG 模板生成一张 1200×630 的分享图（`/og/<文章 ID>.png`，中文需要构建机的 Noto CJK 字体，部署工作流已自动安装），作为文章页的 og:image；其余页面使用 `/social-card.svg`。

站点使用项目 Pages 地址 https://sujinglang.github.io/ginlang/，对应配置在 astro.config.mjs。如果仓库或 GitHub 账号发生变化，请一并更新 site 与 base。

分享给朋友时使用上面的 HTTPS 地址。本地预览使用的 127.0.0.1 地址只能在自己的电脑上打开。线上站点是公开静态网页，无需登录，也不依赖第三方字体或脚本。
