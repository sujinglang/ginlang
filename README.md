# GINLANG

一本文章还在继续增加的中文独立文学小刊。由创办人整理作品，也为受邀作者保留署名与独立页面。使用 Astro 生成静态页面，发布在 GitHub Pages。

视觉规范与动效说明见 [ART_DIRECTION.md](ART_DIRECTION.md)。新增作者、作品和专题的步骤见 [编辑与发布手册](docs/editorial-workflow.md)。

## 写一篇新文章

在 src/content/posts/ 新建 Markdown 文件，例如 2026-10-01-autumn-note.md：

    ---
    title: 秋天经过的时候
    date: 2026-10-01
    category: essay
    author: ginlang
    excerpt: 给文章写一句简短的介绍。
    draft: false
    ---

    从这里开始写正文。

category 可用 essay（随笔）、diary（日记）、book（书摘）或 short（短句）。写作中的文章将 draft 设为 true，发布前改成 false。

`author` 对应 `src/content/authors/` 中的作者 ID。首页会按已发布的真实内容展示作者和作品；未配置正式专题时不会出现空专题入口。

## 本地预览和构建

    npm install
    npm run dev
    npm run build

静态文件会生成到 dist/。推送到 GitHub 仓库的 main 分支后，GitHub Actions 会自动构建并发布。

## 内容与视觉

- 首页依次展示七幅水彩画轮播封面、本期主文与次级作品、客席作者、已发布的专题、页边札记、可切换的风景和分类目录。专题未配置时自然隐藏；作品节选和作者数量由真实内容生成。
- 封面画册每 6 秒翻一张，支持前后切换（按钮或键盘左右方向键）、暂停、继续与手机横向滑动；刷新时会更换首图。网页副本位于 `public/hero-watercolors/`，原始 PNG 保留在用户提供的素材文件夹。画册图片在 `src/components/HeroGallery.astro` 中配置，路径兼容 `/ginlang/`。选定的首图在页面解析时即开始预载，其余按需加载。浏览器启用减少动态效果时，画册默认暂停。
- 留白与暖纸白仍是主体，手绘插画采用低饱和的蓝、绿和陶土色。透明的蓝蝶使用侧展的艺术化蝶翼，不绘制深色虫身。日记页的深色月夜图已换成带一弯月亮的明亮街景。
- 首页「换一扇窗」可以手动切换海边、林间和街角；不自动播放。插画放在 public/，路径由页面组件引用。
- 作者目录和个人页展示选用的海边插画头像与林间水彩扉页；手机端头像居中衔接扉页与简介。网页资源位于 `public/authors/`，原图的本地备份位于未发布的 `source-art/`。作者介绍仍保留待填内容。
- 首页有「随机翻一页」和随刷新轮换的页边札记。
- 各栏目都有「页边札记」。src/data/whispers.ts 收录有出处的白话散文、少量诗词与近现代短句，逐条标注作者和作品；刷新页面或点「换一句」会显示不同的一条，相邻两次不会重复。核对资料见 [选句来源](docs/whisper-sources.md)。
- 「抽一张今日笺」放在关于页的末尾，作为写作邀请。首页简介和关于页五段个人内容目前明确显示「此处需要您亲自填写」；在 src/data/author.ts 替换这些文字即可。

## 阅读与交互

- 文章支持阅读进度、相邻文章和复制链接。长文章出现自动目录；阅读书签能保存当前文章的大致阅读位置，并在再次打开时继续阅读，位置只保存在当前浏览器。
- 阅读设置默认使用浅色纸页，也可调整为跟随系统或夜间主题，并可修改字号、字体风格和正文宽度；偏好保存在当前浏览器。
- 搜索支持文章标题、摘要、署名和分类，也可按 Ctrl+K 或 ⌘K 打开；匹配的关键词会在结果中高亮，用 ↑/↓ 在结果间移动、回车打开。打开搜索时会预先读取索引。
- 文章页可用 ←/→ 方向键在相邻文章间切换；支持系统分享的设备可以直接分享当前文章。
- 向下滚动后右下角出现「回到页首」按钮；文章页它会自动避开阅读书签的位置。页脚标注最近一次的更新日期。
- 页头在阅读向下滚动后收成一条紧凑的细栏，便于继续跳转；回到页首附近时恢复完整高度。
- 页面切换有短促的柔和过渡；封面文字、蓝蝶、文章目录、图片与不同栏目使用各自的轻量动效；风景切换交叉淡入。系统选择减少动态效果时会关闭动画。
- 页眉和页脚都能打开分享面板，一键复制公开网址；支持系统分享的设备也可直接转发。
- RSS 订阅位于 /rss.xml，站点地图位于 /sitemap.xml。
- 页面包含 canonical、Open Graph、Twitter 卡片和结构化数据（全站 WebSite，文章页 BlogPosting，作者页 ProfilePage）。

站点使用项目 Pages 地址 https://sujinglang.github.io/ginlang/，对应配置在 astro.config.mjs。如果仓库或 GitHub 账号发生变化，请一并更新 site 与 base。

分享给朋友时使用上面的 HTTPS 地址。本地预览使用的 127.0.0.1 地址只能在自己的电脑上打开。线上站点是公开静态网页，无需登录，也不依赖第三方字体或脚本。
