# 页边札记：选句来源

`src/data/whispers.ts` 按哲理、人生、爱情、自由、方向整理短摘录，另有一组古典词句单列在 `classics`。全站共用作者交错的洗牌袋，页面切换和同一标签页刷新继续从袋中取句；取完后重洗。同一位作者不会连续出现（仅剩单一作者时除外）。每条在页面上显示作者与篇名。白话部分选句优先取白话文，删去了与这些主题无关的政治和爱国表达，也剔除了部分脱离上下文就失去意义的片段。

早期白话文本与古典词句均逐字核对下列全文。繁简、异体字按简体网页展示；短句可能从长句中截取，句尾标点随截取调整。

## 古典词句

`classics` 只收离别、时光、孤独与自处的句子，不收怀古、将相、故国之思，也不收脱离上下文就不成立的片段。

- 李煜：[《南唐二主词·后主李煜词》](https://zh.wikisource.org/wiki/南唐二主詞)，逐字取自《子夜歌》《乌夜啼》《虞美人》《相见欢》《浪淘沙令》《清平乐》《望江南》《浪淘沙》《捣练子令》《阮郎归》《渔父》《后庭花破子》《临江仙》。
- 纳兰性德：[《饮水词》](https://zh.wikisource.org/wiki/飲水詞)，逐字取自《木兰花令》《画堂春》《采桑子》《浣溪沙》《虞美人》《梦江南》《菩萨蛮》《谒金门》《临江仙》《长相思》《如梦令》《摊破浣溪沙》《金缕曲》《清平乐》《蝶恋花》。

两位作者的作品久已过公有领域期限，但维基文库的标点与异体字整理仍可能与他本校订不同，正式引用前建议再对一次中华书局或上海辞书的通行本。
