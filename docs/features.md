# GINLANG 现有功能与视觉约定

## 内容与视觉

- 首页封面以四行诗句「吹箫凌极浦，／日暮送夫君／湖上一回首，／青山卷白云」和水彩画册开场，保留逗号、不显示句号。桌面端的封面两列在 1040px 内居中，采用 0.85fr / 1fr 的比例与 48px 列距，画册最大约 536px，让诗句与画面靠近而四周仍有留白。作者资料作为独立段落接在最近更新之后，再展示最近文章、客席作者、已发布的专题、页边札记、今日笺、可切换的风景和分类目录。平板沿用现有双列比例，手机端按诗句、按钮、画册、作者资料的顺序阅读。专题未配置时自然隐藏，内容只从真实资料生成，不显示作品或作者计数。
- 首屏按钮分两级：主入口实心、次入口描边，桌面 54px、手机 52px 高度与单层细边线。「开始阅读」在首页定位到最近文章，「认识作者」定位到 GINLANG 的个人资料，减少不必要的跨页跳转。「随机翻一页」仍放在「最近写的」标题旁；桌面常用安静操作保留约 44–46px 的触控高度和透明底色；手机主要入口增至 48px，以常驻细线提示可操作性，不出现孤立白底块。最近主文以整块标题入口打开，不重复设置「阅读全文」。没有真实客席作者时，首页以 `home-guest-invitation` 整块链接呈现邀请：标题在左、「参与写作」在右，说明放在下一行，透明背景下只有一条底线；整块可点击，鼠标悬停、键盘聚焦或触摸按下时整行底线提供反馈。作者目录和投稿页仍可访问。
- 封面画册每 6 秒翻一张，支持前后切换（按钮或键盘左右方向键）、暂停、继续与手机横向滑动；点击画面可以放大翻看，关闭后继续原来的轮播状态。刷新时会更换首图。网页副本位于 `public/hero-watercolors/`，原始 PNG 保留在用户提供的素材文件夹。画册图片在 `src/data/heroWatercolors.ts` 中配置，路径经 `import.meta.env.BASE_URL` 拼装，兼容站点根路径。每张画另有 480w / 800w 两档 WebP 副本，按屏幕尺寸自动选择；更换原图后运行 `node scripts/build-hero-variants.mjs` 重新生成并一并提交。画册下方一条灰绿细线随翻页推进，只暗示位置，不显示数字。选定的首图在页面解析时即开始预载，其余按需加载。浏览器启用减少动态效果时，画册默认暂停。
- 首页画册下方通向 `/album/` 相簿页。相簿按作者分开：GINLANG 的相册排在最前，客席作者的相册作为次级列表；每位作者的相册有稳定地址（`/album/<作者 id>/`），可从作者主页直接进入，相册页也能回到作者主页。相册数据在 `src/content/albums/<作者 id>.json`，没有公开照片时只显示「暂未公开照片」，不借用其他图片填充；作者主页的照片推荐与相册页读取同一份数据。首页水彩轮播的图片与替代文本由 `src/data/heroWatercolors.ts` 维护。
- 画册边有「做张小卡片」入口，可从现有水彩和已标注出处的短句中选取内容，在浏览器内排版并下载 PNG。图片完整放进纸白画框，文字列在下方；不会向网站上传个人数据。选句在 `src/components/CardMaker.astro` 中维护，仍从 `src/data/whispers.ts` 的有效句库读取。
- 留白与暖纸白仍是主体，手绘插画采用低饱和的蓝、绿和陶土色。透明的蓝蝶使用侧展的艺术化蝶翼，不绘制深色虫身。日记页的深色月夜图已换成带一弯月亮的明亮街景。
- 首页「换一扇窗」可以手动切换海边、林间和街角；不自动播放。插画放在 public/，路径由页面组件引用。
- 首页作者资料、作者目录和个人页共用海边插画头像与林间水彩背景；首页背景保持完整 3:2 横幅，头像与图片分开，桌面头像为 172px、手机为 146px。桌面视觉列的起点接近地点日期与 About 之间，避免图片随长引文居中下沉。地点「成都」和原样日期「07/02/18」由 `src/content/authors/ginlang.json` 提供，日期不预设用途。首页与关于页的 `Hi! I'm GINLANG.` 整句使用一个文本节点和既有自托管 Marck Script Regular 400，不描边、不模拟加粗、不使用首字下沉；About 与英文引文也使用 Marck Script，中文引文使用 Zhi Mang Xing，其他界面继续使用阅读字体。中文出处留在作者数据中供核对，不在页面显示。网页资源位于 `public/authors/`，原图的本地备份位于未发布的 `source-art/`。
- 首页有「随机翻一页」和随刷新轮换的页边札记。今日笺下方会在读过文章后安静地出现一行「上次读到《……》」，点击即可回去继续；记录只保存在当前浏览器。
- 各栏目都有「页边札记」。`src/data/whispers.ts` 收录有出处的白话短摘录，围绕哲理、人生、爱情、自由和方向；全站共用作者交错的洗牌袋，跨页面与同一标签页刷新不重复，轮完再洗牌。核对资料见 [选句来源](docs/whisper-sources.md)。
- 「抽一张今日笺」放在首页，读者可以在网页上写草稿、复制或清空；不同笺语的草稿分别保存在自己的浏览器，也可在「我的书桌」整理和导出。关于页用作者文章入口替换。首页末尾和关于页五段待填内容仍显示「以后再来写吧」；在 `src/data/author.ts` 替换这些文字即可。
- 页脚使用不蒜子统计累计访问人次；静态部署后加载，外部服务暂不可用时显示破折号。同一浏览会话只计数一次，刷新页面不会累加；最近一次读到的数字会缓存在浏览器里继续显示。本地开发不会请求计数服务。统计服务的访问记录处理方式见[不蒜子说明](https://www.busuanzi.cc/doc.php)。

## 阅读与交互

- 文章支持阅读进度、相邻文章和复制链接。长文章出现自动目录，滚动时目录会标出当前所在的小节；阅读书签能保存当前文章的大致阅读位置，并在再次打开时继续阅读，位置只保存在当前浏览器。夜间主题下，画框类图片带柔和投影。
- 阅读设置默认使用浅色纸页，也可调整为跟随系统或夜间主题，并可修改字号、字体风格和正文宽度；偏好保存在当前浏览器。
- 搜索支持文章标题、摘要、正文、署名和分类，也可按 Ctrl+K 或 ⌘K 打开；正文命中时显示附近的一小段，匹配的关键词会在结果中高亮，用 ↑/↓ 在结果间移动、回车打开。搜索词可通过带 `?q=` 的网址分享。打开搜索时会预先读取索引。
- 「我的书桌」位于 `/desk/`，汇集手动收藏的文章、原有阅读书签和今日笺草稿，可导出为 Markdown。所有数据只保存在当前浏览器，换设备或清除浏览器数据后不会自动同步；导出文件适合自行备份。桌页另有「备份为 JSON」：生成带版本号的 `ginlang-书桌备份-<日期>.json`，包含收藏文章 ID、每个阅读书签的网址与阅读比例、笺语草稿，换一台浏览器后可以恢复。「从备份恢复」读取该文件，先显示将新增多少内容，确认后按身份合并——同一条收藏或书签不会被添加两次，重复导入同一个文件不会改变结果，已有内容不会被删除。现有 Markdown 导出与全部浏览器存储键保持不变。
- 文章支持可选标签：在头部写 `tags: [阅读, 独处]` 即可，旧文章没有该字段也能正常构建。标签页位于 `/tags/` 与 `/tags/<标签>/`，归档页顶部的标签行按 `?tag=<标签>` 筛选，与搜索的 `?q=` 用法一致；相关文章会优先参考共同标签，再看共同主题与分类。标签目录会写进网站地图。
- 作者相册支持可选分组：在相册 JSON 的 `groups` 里登记分组，照片用 `group` 指向分组 ID；没有 `groups` 的旧相册继续把所有照片放在同一个网格里，不会隐藏任何一张。分组超过一个时页面顶部出现分组导航，点击照片可按原比例放大，用 ← → 或方向键前后切换、Esc 关闭，关闭后回到原来的照片位置。分组内照片在大图里仍按整册顺序连续出现。
- 每篇文章底部预留留言区，位置在页脚之后、相邻文章之前。留言由独立的 Waline 服务端承载，读者填名字即可留言、无需注册，提交后直接公开显示。地址写在 `src/lib/comments.ts` 的 `serverURL`，留空则整块不渲染。前端脚本按需加载不占首屏体积，服务端不可用时显示一句中文提示而不留空白框。留言数据存在 LeanCloud，不在仓库内；部署步骤见 [留言](docs/editorial-workflow.md#留言)。
- 本机内容工作台（`npm run workbench`）在本机 `127.0.0.1:4322` 提供表单：新建草稿、改文章头部、加客席作者、导照片、查看内容、运行文库核对。它不构建、不发布，也不进入线上网站，生成的 Markdown 与 JSON 和命令行完全一致。
- 文库与今日笺分开维护：`src/data/whispers.ts` 只放有出处的原文摘录，`src/data/dailyNotePrompts.ts` 放本站原创的今日笺段落，不署名家。`npm run check:library` 核对摘句出处、重复、作者分布，并检查今日笺不用问句、不空泛、不与文库重复。
- 文章页可用 ←/→ 方向键在相邻文章间切换；支持系统分享的设备可以直接分享当前文章。
- 向下滚动后右下角出现「回到页首」按钮；文章页它会自动避开阅读书签的位置。页脚标注最近一次的更新日期。
- 页头导航与工具适度放大，保持纸白底色与清楚的分隔线；页眉、页脚的小花标识采用同形细线 SVG，避免在 iPhone 上显示为彩色 emoji；阅读向下滚动后收成一条紧凑的细栏，回到页首附近时恢复完整高度。手机目录在正常页面流中展开。
- 带底线的常用跳转与操作统一使用细线反馈：桌面灰线保持原位，有鼠标悬停能力且使用精细指针时，陶土红线在约 460 毫秒内从左向右铺开，起止放缓；键盘聚焦同样有明确反馈。首页最近更新、主文与次文，以及分类页、文章目录、作者作品和归档中的文章标题采用同一套铺线反馈；标题没有常驻灰线，鼠标或键盘进入条目时展开陶土色线，原有整行或整块点击区域继续保留。专题作品、主题阅读路线与关于页的文章入口沿用同一节奏。手机主要安静入口采用常驻 12px 陶土色线段与其余灰线，触控高度 48px，读者无需捕捉短暂按压动画。首页邀请以整行底线反馈；导航与文章筛选的选中项常驻红线。手机风景选择保留原有轻量文字入口，48px 触控高度；仅选中项与悬停项显示细红线，不使用整组外框或选中底色。背景线条不改动整块点击范围或页面高度；减少动态效果时缩短过渡。
- 页面切换始终保留短促的纸页淡入过渡；封面文字、蓝蝶、文章目录、图片与不同栏目使用各自的轻量动效；风景切换交叉淡入。系统选择减少动态效果时，其余连续动画会停止或缩短。
- 页眉和页脚都能打开分享面板，一键复制公开网址；支持系统分享的设备也可直接转发。
- RSS 订阅位于 /rss.xml，正文以全文输出（content:encoded）；站点地图位于 /sitemap.xml。
- 页面包含 canonical、Open Graph、Twitter 卡片和结构化数据（全站 WebSite，文章页 BlogPosting，作者页 ProfilePage）。每篇文章在构建时由 SVG 模板生成一张 1200×630 的分享图（`/og/<文章 ID>.png`，中文需要构建机的 Noto CJK 字体，部署工作流已自动安装），作为文章页的 og:image；其余页面使用 `/social-card.svg`。

站点使用主域名 https://ginlang.vip/ ，对应配置在 astro.config.mjs（`site: 'https://ginlang.vip'`、`base: '/'`）。如果域名或仓库发生变化，请一并更新 site 与 base。

分享给朋友时使用上面的 HTTPS 地址。本地预览使用的 127.0.0.1 地址只能在自己的电脑上打开。线上站点是公开静态网页，无需登录，字体由站内文件加载；页脚计数使用前述第三方统计服务，其余阅读与交互不依赖该服务。
