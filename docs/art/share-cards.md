# 主链接与文章分享封面

主链接：`https://ginlang.vip/`。浏览器、OG 与 Twitter 标题均为 `GINLANG`，简介为「GINLANG 的个人博客。记录随笔、日记和读书时的想法。」

固定首页封面位于 `/social-card.png`。使用既有首页四行诗与 `public/hero-watercolors/04-boat-under-clouds.webp`，不随轮播、阅读主题或设备变化。网站标签由 Astro 在构建时输出，不依赖客户端脚本。

## 设计

- 1200×630 PNG；纸白 `#f5f2eb`、墨色 `#292b27`、灰绿 `#40574a`、灰字 `#65685f`、细线 `#dad5cb`、小花陶土色 `#a66048`。
- 沿用博客的中文宋体与朴素品牌字。左侧四行诗，右侧完整水彩，下方列内容类型与域名；不增加新的宣传口号。
- 文章共用相同边距、品牌小花和细线。标题、摘要在左，作品现有图片在右；《萧萧秋风》使用海河夜景。《无望之后的供词》没有配图，使用宽版文字封面，也不输出作者署名。
- 图片在画框内按自然比例完整缩放。长标题自动减字号、换行；过长摘要仅在图片里截短，原始 OG 简介与正文不变。中文标点不落在行首。

统一生成器：`src/lib/shareCard.ts`。构建机沿用现有 Noto CJK 字体安装步骤。标题、摘要、署名、原图字节和模板版本生成 URL 指纹，避免换图或改题仍指向同一缓存键；文章稳定地址不变。

## 检查

`npm run check:site` 对全部构建页面检查 OG/Twitter 标题、简介、正式网址、图片地址与版本、PNG 实际尺寸、图片体积、替代说明，以及文章结构化数据和匿名信息。

2026-10-06 已查看首页、两篇文章的实际 PNG；在 1280px 桌面与 390px 手机上检查首页标题、浅色、夜间和横向溢出。正文、作者资料与原图片不改动。

[Open Graph 协议](https://ogp.me/)规定网页提供标题、类型、图片、正式网址及可选简介。网站可以提供这些信息，聊天软件如何抓取、缓存或呈现卡片仍由该软件决定；这些验收不等于已在微信聊天里实际发送并看到卡片。
